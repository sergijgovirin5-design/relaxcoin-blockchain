# RelaxCoin Integration

Этот проект содержит смарт-контракт `RelaxCoin (R2R)` и интеграции с Hardhat.
R2R — это ERC-20-токен в EVM-сети, а не собственная монета или отдельный блокчейн.
Настроенный Chain ID `271828` используется для локальной сети Hardhat; это не production-сеть.

## Как подключиться к RelaxCoin

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите локальный узел Ethereum или Hardhat node:
   ```bash
   npx hardhat node
   ```

3. Запустите скрипт подключения:
   ```bash
   RELAXCOIN_ADDRESS=<адрес_контракта> RPC_URL=http://127.0.0.1:8545 node scripts/connectRelaxCoin.js
   ```

Если `RELAXCOIN_ADDRESS` не задан, скрипт развернет новый контракт `RelaxCoin` и подключится к нему.

## Проверки

```bash
npm run compile
npm test
```

`npm test` запускает контракты на встроенной локальной сети Hardhat. Для развёртывания
в другой EVM-сети нужны её RPC, адреса контрактов и production-оракул.

Мобильный `Thone` использует WalletConnect для подписи пользовательских token-creation
и payment транзакций внешним EVM-кошельком. Он не создаёт и не хранит seed-фразы или
private keys. Для сборки сначала создайте embedded WalletConnect-страницу по
инструкциям в `Sait_Storinck/Metamasc_Conect/Thone/README.md`.

В конфигурации этого проекта нет production EVM-сети; `npm run deploy` разворачивает
контракты на локальном Hardhat RPC. Не публикуйте RPC Hardhat-ноды в интернете.
Для телефона нужны factory/token addresses в реально доступной сети, совпадающий
chain ID и HTTPS RPC, доступный и устройству, и подключённому кошельку.

## Пользовательские токены и оплата 70/30

`R2RTokenFactory` создаёт отдельные ERC-20 токены: при выпуске 70% указанного предложения
получает создатель, а 30% — платформенный адрес. При оплате через функцию `pay` в таком
токене 70% суммы получает продавец/получатель и 30% переводится на платформенный адрес.
Обычный ERC-20 `transfer` не облагается этой комиссией; платёж должен быть отправлен
именно вызовом `pay`. Поэтому прямой перевод токена не распознаётся как покупка и не
обеспечивает сбор комиссии.

Адрес комиссии задаётся при создании токена и остаётся закреплённым за ним. Успешное
создание и оплата также требуют нативную монету сети для gas; «бесплатно» означает
отсутствие отдельной цены за создание, а не отсутствие сетевой комиссии.
Скрипт `npm run deploy` разворачивает фабрику и печатает её адрес; кошельку нужно
передать этот адрес в поле фабрики. Для получателя 30% задайте
`RELAX_TOKEN_FEE_WALLET`; если переменная не задана, используется treasury wallet.

## Пример использования

- `connectRelaxCoin.js` подключается к контракту `RelaxCoin`
- читает `name`, `symbol`, `totalSupply` и баланс владельца
- отправляет `1 R2R` на адрес `RECEIVER_ADDRESS`, если он задан
